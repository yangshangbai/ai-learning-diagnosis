## 修复后的闭环(目标态)

```
教师建任务(draft) → 分配学生(pending) → 打印答题卡(四角定位+二维码)
→ 拍照上传:前端调 GLM-4V 识别(key 服务端优先) → 仅按识别学号精确匹配
   ├─ 匹配 → POST /exam-tasks/{id}/answer-sheets(含 answers) → 旧卡 superseded
   │          → question_scores 入库(student_answer) → 客观题服务端判分 → in_exam
   └─ 不匹配 → 跳过 + 提示人工指认(禁止顺序兜底)
→ 「AI重新判分」→ 服务端确定性重判(保教师分) → scoring
→ 教师调分(PATCH,0~满分校验) → 看板实时聚合(只算 active 卡)
```
