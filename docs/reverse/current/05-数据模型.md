> 基线 `ff622a7`(v2.0.0) | 2026-08-29

## 1. 系统与认证(system_models.py)
| 表 | 核心字段 | 说明 |
|----|---------|------|
| users | username(唯一), password_hash(sha256), name, **role=admin/teacher**, permissions(JSON), teacher_id, is_active | 权限 JSON 仅非 admin 落库 |
| system_logs | level(4级), source(frontend/backend), module, message(≤4000), detail, traceback, url, user_id, username, request_id, **repaired/repaired_at/repaired_by/repaired_note** | 错误闭环;复合索引 (level,source),(repaired,created_at) |

## 2. 基础数据(basic.py / tag.py)
| 表 | 核心字段 | 说明 |
|----|---------|------|
| categories | parent_id(自引用树), category_type(9种: subject/grade/knowledge/question_type/difficulty/question_bank/question/paper/task), code(KP码/编号码段), extra JSON(grade.stage 等), status | 学科/年级/知识点/题型/难度全在此表 |
| tags | name(唯一), color(red/blue/orange/green) | questions.tags 存 tag id |

## 3. 组织(teacher.py / class_model.py / student.py)
| 表 | 核心字段 | 说明 |
|----|---------|------|
| teachers | user_id→users, teacher_code(唯一 T0001 式), name, gender, phone, subject_ids(JSON→categories), status | |
| teacher_classes | teacher_id, class_id, **role=head_teacher/subject_teacher**(班主任每班唯一), subject_id | 教师数据域的依据 |
| classes | class_code(唯一,学段前缀 A小学/B初中/C高中), name, stage(primary/middle/high), status | |
| students | student_code(唯一 A01-Z99), name, gender, **class_id 非空**, birth_date, parent_name/phone, enrollment_date, initial_evaluation, **recent_evaluations(JSON 考后评价)**, status | |
| class_statistics | class_id 一对一, 19+ 统计字段(均分/及格/优秀/分布/能力分组/知识点掌握/进退步/前后榜 JSON) | ⚠️ 看板走实时聚合,本表闲置 |

## 4. 学生统计(student.py)
| 表 | 说明 |
|----|------|
| student_statistics | student_id 一对一;考试次数/参与率/分数三元/班级排名/题型正确率/知识点掌握/薄弱点/进退步 — ⚠️ 闲置 |

## 5. 题库(question.py)
| 表 | 核心字段 | 说明 |
|----|---------|------|
| questions | question_code(唯一 `MAT-G7-KP003-0027` 式), source(manual/jiaoyanyun), source_id(教研云题ID,**去重键**), subject_id/grade_id/category_id→categories, ques_type(5值: single_choice/multi_choice/fill_blank/true_false/essay), difficulty(1-5), **stem(HTML 含公式/图片)**, options(JSON), answer, analysis, score, knowledge_ids(JSON), tags(JSON), images(JSON), status | |
| question_images | question_id, url | 题图 |
| import_logs | 新旧双套字段并存(source/total/success/failed + file_name/format/success_count/fail_count/status) | ⚠️ 双套字段(技术债) |

## 6. 试卷与模板(paper.py)
| 表 | 核心字段 | 说明 |
|----|---------|------|
| papers | paper_code(唯一), name, category_id/subject_id/grade_id, total_score, question_count, status=draft/active/archived | |
| paper_questions | paper_id, **question_id 可空(删题留快照)**, sort_order, score, answer_key, analysis | 组卷快照,与题库解耦 |
| answer_sheet_templates | paper_id 一对一, layout_config(JSON), 文件字段, source=auto/user | 后 6 列由 migrate_templates.py 补齐 |
| paper_templates | paper_id 一对一 **ON DELETE CASCADE**(全库唯一 DB 级联), layout_config, updated_by | |
| paper_drafts | user_id 唯一, questions(JSON 题目 id 数组) | 组卷草稿 |
| ai_selection_banks | user_id, title(提示词), subject/grade_group/grade/semester/category, type_config(JSON), difficulty_ratio(JSON), plan(JSON), questions(JSON), total_score, status=draft/confirmed/synced | AI 选题结果 |

## 7. 考试与评分(exam.py)
| 表 | 核心字段 | 说明 |
|----|---------|------|
| exam_tasks | task_code(唯一), name, paper_id 非空, category_id, creator_id→teachers 可空, **status 六态** | |
| task_assignments | task_id, student_id, **class_id(创建时快照)**, status=pending/uploaded/scored/confirmed | |
| answer_sheets | task_id, student_id, image_urls(JSON), upload_type(camer/file), upload_device, record_status, **ai_status=pending/processing/completed/failed**, ai_started_at/completed_at | |
| question_scores | answer_sheet_id, task_id, student_id, paper_question_id, question_number, student_answer, correct_answer, ai_score/ai_max_score/**ai_confidence(0-1)**/ai_explanation/ai_raw_output(JSON), teacher_score, **final_score(教师优先)**, score_status=ai_scored/teacher_confirmed/teacher_modified | 评分事实表 |
| task_statistics | task_id 一对一, 19 统计字段 | ⚠️ 闲置 |

## 8. 关系总图(文字版)

```
users 1—1 teachers 1—N teacher_classes N—1 classes 1—N students
users.permissions(JSON); teachers.subject_ids → categories

categories(自树) ← subject_id/grade_id/category_id/knowledge_ids — questions / papers / exam_tasks / teachers

papers 1—N paper_questions N—1 questions(可空,快照)
papers 1—1 paper_templates / answer_sheet_templates / paper_drafts(按用户)

papers 1—N exam_tasks 1—N task_assignments N—1 students
exam_tasks 1—N answer_sheets 1—N question_scores N—1 paper_questions

questions 1—N question_images; questions.tags/tags(JSON 引用)
ai_selection_banks →(confirm)→ questions
```
