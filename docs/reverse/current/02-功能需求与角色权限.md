# 02 — 功能需求与角色权限

> 基线 `ff622a7`(v2.0.0) | 2026-08-29

## 1. 角色模型(v2 现状)

**仅两种角色**: `admin` / `teacher`(`backend/app/models/system_models.py:34`)。旧版的 research/super 已废弃(仍残留在旧 Vue SPA/AGENTS 中,见技术债 #16)。

### 权限模型: 模块 × 动作勾选
- 11 个业务模块(`backend/app/core/security.py:30-42`): `question`(题库) `paper`(试卷) `exam`(考试) `student` `class` `teacher` `user` `ai` `ai_select` `sync`(教研云同步/导入) `system`
- 4 种动作: `view / add / edit / delete`
- 规则:
  - admin 恒全量,不落库(`security.py:64-72,106-111`)
  - 非管理员权限存 `users.permissions` JSON(`system_models.py:27-39`)
  - `user`、`system` 为敏感模块,教师默认权限=非敏感模块的 view+add+edit(`security.py:47,55-61`)
  - 权限即时生效:`get_current_user` 每请求回查 DB(`security.py:138-151`)
- 教师数据域: 经 `teacher_classes` 关联班级限定(`backend/app/core/permissions.py:12-21`),各 router 逐条校验越权 403
