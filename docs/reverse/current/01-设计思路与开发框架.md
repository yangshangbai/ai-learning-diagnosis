## 1. 设计思路(v2 重设计解决了什么)

| 设计决策 | 具体做法 | 证据 |
|---------|---------|------|
| 后端整体分层 | 旧扁平 `backend/api/` → 新 `backend/app/{core,models,routers,schemas}` 四层 | `backend/app/` 目录结构 |

## 2. 后端框架

| 项 | 值 | 证据 |
|----|----|------|
| 框架 | FastAPI 0.115.0 + Uvicorn/Gunicorn(UvicornWorker) | `backend/requirements.txt` |
| ORM | SQLAlchemy 2.0.35,连接池 pool_size=10/max_overflow=20/pre_ping | `backend/app/core/db.py:15-31` |
| 校验 | Pydantic 2.9.2 + pydantic-settings | `backend/requirements.txt` |
| 认证 | JWT(HS256,1 天),payload 仅 user_id/role/name/teacher_id;**每请求回查 DB** 刷新权限/禁用 | `backend/app/core/security.py:78-151` |
| 密码 | 无盐 sha256(⚠️ bcrypt 已装未用,见技术债 #6) | `backend/app/routers/auth.py:32-33` |
| 建表 | 无 Alembic;启动期幂等 DDL(create_all + 补列 + 修补数据) | `backend/app/seed.py:153-173` |
| 生产驱动 | psycopg2-binary(PostgreSQL 16) | `backend/requirements.txt`、`backend/.env` |

**入口装配**(`backend/app/main.py`):
- lifespan: 所有环境跑 `seed.ensure_schema_migrations()`;dev/test 另做 create_all + `seed_admin()`(admin/admin123)+ `seed_basic_data()`(学科5/年级12/题型5/难度5)(`main.py:42-54`)
- 中间件: CORS(白名单来自 settings)→ request_id 中间件(`main.py:59-78`)
- 路由挂载 18 个,顺序关键: `import_export` 先于 `question` 注册,避免 `/questions/export-template` 被 `/questions/{qid}` 抢匹配(`main.py:132`)

## 5. 部署拓扑

```
用户 → Nginx(80/443, 静态+SPA兜底, /api→8001 含/v1映射)
     → Gunicorn :8001 (systemd ai-learning, WorkingDirectory=/opt/ai-learning/backend,
        ExecStart=venv/bin/python -m gunicorn -c gunicorn_conf.py -k uvicorn.workers.UvicornWorker app.main:app)
     → PostgreSQL 16 (127.0.0.1:5432/ai_training)
教研云链路(同机): Chrome(CDP:9222) ← sync/playwright;proxy :8787 ← FastAPI ai_select / demo SPA
运维: scripts/run_repair.sh cron(8/11/17/22点) → auto_repair.py 自动分类/修复错误日志 + git 自动提交
```
- 部署脚本: `scripts/quick-sync.sh`(仅后端)/`quick-full.sh`(前后端,服务器端 npm build)/`deploy.sh`(全量带选项),全部 tar+ssh(`YunServerMG.pem`)
- 生产关闭 FastAPI docs(实测 /api/docs、/openapi.json 404);/health、/ready 挂应用根,被 nginx 兜底,外网探不可用
